                                                                                         ## 😈 Tool description
                                                                                         
                                                                      TITAN is a lightweight security tool built by **IMAD** ⚡. 
                                                                                    It helps you:
                                                                               - 🔎 Find the **IP address** of a target website.
                                                                               - 🌍 Scan **paths/endpoints** from a wordlist.
                                                                               - 📡 Check if the target **website is up or down**.
                                        
                                                                                          ## 🚀 Features
                                                                                            
                                                   
				                                                               - Fast and multithreaded path,ip,site status scanning.
					                                                           - Graceful exit with CTRL + C.
					                                                           - Easy to use for beginners. 
					                                                           
					                                                                      ## ⚙️ Usage
					                                                                      
					                                                                      
					                                                           -python3 titan.py ip
					                                                           -ython3 titan.py paths -u http://example.com -w wordlist.txt -t 10
					                                                           -python3 titan.py code
					                                                          
					                                                                      ## 🛠 Requirements
					                                                                      
					                                                        
					                                                           - Python 3.8+
					                                                           - `requests`
					                                                           - `rich`
					                                                           - `pyfiglet`
